Healthcare / Web platform

Healthcare Compare

↗

A UK healthcare directory project focused on helping people explore providers, locations and treatments through a structured web experience.

Visit Healthcare Compare ↗
Inside the project

Development work spans a React interface, Node.js APIs and a PostgreSQL-backed provider directory. The project demonstrates how a clear customer-facing experience can connect with structured information and systems behind the scenes. It is presented as a platform project, without claims about unverified commercial results.
