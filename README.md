# NovaLynth Portfolio

Static portfolio website. No npm installation or build step is needed.

## Publish with GitHub Pages

1. Extract the ZIP on your computer.
2. Create a public GitHub repository named `novalynth-portfolio`.
3. Upload `index.html`, the complete `assets` folder and this README to the repository root. Upload the extracted files, not the ZIP or its enclosing folder.
4. Commit the files to `main`.
5. Open Settings → Pages.
6. Under Source, select Deploy from a branch.
7. Select `main` and `/(root)`, then Save.
8. Wait for deployment, then use the Visit site button on that page. Publication can take up to 10 minutes.

Clients can open the resulting website without a ChatGPT account. GitHub Free requires a public repository for this setup.

Edit `index.html` to change copy, styles or contact details. Keep the images inside `assets` alongside the HTML file. Fonts are loaded from Google Fonts, with system font fallbacks.
